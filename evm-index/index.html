evm-index · what it does

A framework for indexing EVM chains.

Two frameworks, each usable alone: tracks run by an indexer, and a fetch layer. Nine scenes, from the base case up, each looping until you move on.

    A trackone function per log, with state of its own

    One call per log, in order. The state is loaded before each call and committed with the cursor.

    #[derive(State)]
struct Ledger { balance: Map<Address, Amount> }

/// Every log of the token, from its creation, in order.
#[track(version = 1, emits(Transfer))]
async fn token_transfers(t: &Track, token: &Contract, log: Log, state: &mut Ledger) -> anyhow::Result<()> {
    let Some(Event::Transfer(e)) = log.event() else { return Ok(()) };
    let before = state.balance.get(&e.to).await?.unwrap_or_default();
    state.balance.set(e.to, before + e.value)?;
    t.emit(Transfer { token: token.address, from: e.from, to: e.to, value: e.value })
}

    Reading the chainat the block the track is at

    Calls run at the block being processed. Calls of every track at a block go out together.

    /// Every 15 minutes (the first block at or after each boundary), for every pool.
#[track(version = 1, emits(PoolTvl), every = 900)]
async fn pool_tvl(t: &Track, pool: &Contract, _: Tick) -> anyhow::Result<()> {
    let (supply, held) = t.calls((
        (pool.address, totalSupplyCall {}),
        (pool.address, balanceCall {}),
    )).await?;
    t.emit(PoolTvl { pool: pool.address, supply, held })
}
// One call: t.call(pool.address, totalSupplyCall {}).await?   Another block: t.call_at(block, ..)

    Tracks form a graphdiscover contracts, spawn one track each, read other tracks' facts

    A track finds contracts and starts others, and may read what others emit, in block order. Tracks make an acyclic graph.

    /// Polls an API for contracts to follow. Each new one is asked where it was created
/// (an explorer, or a factory's announcement), then tracked from that block.
#[track(version = 1, emits(Discovered), spawns(TokenTransfers))]
async fn discovery(t: Track, api: ApiParams) -> anyhow::Result<()> {
    let mut answers = t.poll(Api::new(&api.url), Duration::from_secs(60));
    loop {
        for token in answers.next().await?.new_contracts() {
            let Some(creation) = t.creation(token).await? else { continue };
            t.emit(Discovered { address: token, block: creation.block })?;
            t.spawn::<TokenTransfers>(Contract { chain: api.chain, address: token, from: creation.block })?;
        }
    }
}
// A factory's logs do the same with t.created(e.token) and #[track(.., announces_creations)].

/// Each Transfer with the USD price in force at its block: two tracks' facts, in block
/// order. If either track rewinds, this one rewinds with it.
#[track(version = 1, emits(PricedTransfer))]
async fn priced_transfers(t: Track, token: Contract) -> anyhow::Result<()> {
    let mut input = t.merge(
        t.facts::<Transfer>(track_id::<TokenTransfers>(&token), token.from),
        t.facts::<Price>(track_id::<TokenPrices>(&token), token.from),
    );
    let mut usd = None;
    loop {
        match input.next().await? {
            Either::Right(price) => usd = Some(price.usd),
            Either::Left(tr) => if let Some(usd) = usd { t.emit(PricedTransfer { usd: tr.value * usd, ..tr })? },
        }
    }
}

    crates/evm-data/indexer · evm-indexer-*

    Tracks, run by an indexer

    A track is a function called once per input, in order, with a state struct of its own. The indexer runs one per contract with its own cursor, rewinds on reorgs, rebuilds a kind from the persistent store when its logic changes, and commits facts as Delta or Postgres tables. design.md, storage.md.

    crates/evm-data/fetch · evm-fetch-*

    A fetch layer

    Callers say what they need and how urgent it is, never which source. Needs are packed into as few requests as the sources take, each sent where price plus the worth of the wait is lowest, under the budget and rates you declare. Nodes, explorers and HTTP APIs alike; every one learned by using it. fetch-algorithm.md, with what was measured.
